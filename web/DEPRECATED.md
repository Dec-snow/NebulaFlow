# ⚠️ 废弃说明 / DEPRECATED

本目录（`web/`）是 NebulaFlow 的初代前端原型，已被 **`web-next/`** 完全替代。

## 为什么废弃

- 技术栈陈旧：初代版本使用较简单的组件结构，未形成完整的设计系统
- 功能不全：仅覆盖核心工作流编辑页，缺少 Dashboard、成本分析、Agent 市场等模块
- 维护成本高：两套前端并存会导致样式、类型、交互逻辑重复维护

## 当前状态

- ❌ 不再新增功能
- ❌ 不再修复 Bug
- ❌ 不再同步后端 API 变更

## 迁移到 web-next

所有新功能与优化都在 `web-next/` 中进行，它包含：

- 完整的设计系统（Design Tokens + UI 组件库）
- 全部页面：控制台、工作流、任务、模板市场、Agent、知识库、模型、成本分析
- React Flow 驱动的可视化工作流编辑器
- i18n 国际化（中/英）
- Zustand 状态管理
- 明暗主题切换

## 删除计划

本目录将在后续版本中移除。如有依赖，请尽快迁移到 `web-next/`。
